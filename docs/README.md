# Web VR video player

A self-hosted WebXR video library for stereoscopic 180° and 360° video, with
an in-headset library browser and playback controls. This project began as a
fork of [michal-repo/web_vr_video_player](https://github.com/michal-repo/web_vr_video_player).

## Documentation

- [Get started](getting-started.md) — requirements, configuration, local development, and builds.
- [Deploy with Nginx](deployment.md) — production deployment and the Nginx example.
- [Catalogue and video formats](catalogue.md) — generate and edit `files.json`.
- [Prepare media for streaming](media-preparation.md) — thumbnails and safe MP4 remuxing.
- [Using the player](using-the-player.md) — library features and controller controls.
- [Troubleshooting](troubleshooting.md)
- [Vendored dependencies](vendored-dependencies.md)
